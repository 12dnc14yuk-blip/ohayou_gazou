透過の手直し機能はそのまま。今回はデザインをさらに盛りました。 大きい絵文字＋小さい絵文字＋太めのかわいいフレームをランダム配置。 「全部ランダム」で毎朝ガチャできます。今回は輪郭アシスト付きの透過手直しはそのままに、顔全体は完全保護へ戻しました。絵文字は顔の外側・髪・肩・服まわりには置けますが、顔の中には入らないように調整しています。女の子はランダムで勝手に左右反転しません。
① 今日の配信スクショを選んでください。
① 今日の女の子を入れる
② 透過を手直しする
白い服・羽・髪が消えたら「消えた部分を戻す」でなぞってください。 今回は輪郭アシスト付きなので、線画や輪郭の近くをなぞると、そのアウトラインに寄せて戻し・消しをしやすくしています。細部は「✏️ 細かく 10」がおすすめ。消しすぎ・戻しすぎは上の透過をひとつ戻す / 進むでやり直せます。精密ブラシ v3
③ 文字
文字は丸ゴシック系を優先して表示。濃いめパステル＋白ふちで、ぷっくり可愛い見た目にしています。
文字色は濃いめパステル＋白ふちで自動統一。暗い色にはならず、背景が明るくても読みやすい設定です。
④ デザインを作る
センス重視モード：四隅すべてに大きい飾りを必ず置き、アバター側上＋文字側下をメイン、文字側上＋アバター側下をサブとして対角に固定します。さらに上下左右と文字の下へ、四隅より少し小さめと小さめの2段階絵文字をもっと多く散らし、顔周辺だけ避けて、上下左右と文字下の空白をしっかり埋めます。文字は常に最前面に表示します。
飾りは空白を埋めるようにバラけて配置。四隅の大きい飾りはアバターより前に出し、中〜小飾りは顔・文字ブロックを避けながら、上下左右と文字下の余白を優先的に埋めます。今回はiPhone絵文字っぽい表示に寄せ、外周だけでなく内側の空白にも散らします。
重なり順：背景 → フレーム → 女の子 → 絵文字（飾り） → おはようメッセージ
春・夏・秋・冬 / 花 / ハート / 星 / リボン / おかし のテーマを追加。テーマを選んだ瞬間に反映されます。ごちゃまぜなら今まで通り、可愛い絵文字を大小たくさん混ぜて使います。できるだけパターン数を増やして、毎回ちょっと手作り感が出るようにしています。
