🌞 おはよう画像メーカー v4.0

透過の手直し機能はそのまま。今回はデザインをさらに盛りました。 大きい絵文字＋小さい絵文字＋太めのかわいいフレームをランダム配置。 「全部ランダム」で毎朝ガチャできます。
① 今日の配信スクショを選んでください。
① 今日の女の子を入れる
② 透過を手直しする
白い服・羽・髪が消えたら「消えた部分を戻す」でなぞってください。 今回は硬めブラシが初期設定なので、前みたいに輪郭がふわっと溶けにくくなっています。 細部は「✏️ 細かく 10」がおすすめ。消しすぎ・戻しすぎは上の透過をひとつ戻す / 進むでやり直せます。精密ブラシ v2
③ 文字
文字は丸ゴシック系を優先して表示。濃いめパステル＋白ふちで、ぷっくり可愛い見た目にしています。
文字色は濃いめパステル＋白ふちで自動統一。暗い色にはならず、背景が明るくても読みやすい設定です。
④ デザインを作る
センス重視モード：大きい飾りは2〜3個だけを端から大胆に見せ、中サイズでつなぎ、小さい飾りで余白を埋めます。顔と文字まわりはしっかり抜き、テーマごとに大きい主役飾りも選び分けます。下の文章は自然な2行を優先して自動調整します。
飾りは空白を埋めるようにバラけて配置。顔が来る真ん中付近には置かず、まわりは重なってもOK。文字は飾りより前に表示されます。
重なり順：背景 → フレーム → おはようメッセージ → 女の子 → 絵文字（飾り）
春・夏・秋・冬 / 花 / ハート / 星 / リボン / おかし のテーマを追加。テーマを選んだ瞬間に反映されます。ごちゃまぜなら今まで通り、可愛い絵文字を大小たくさん混ぜて使います。できるだけパターン数を増やして、毎回ちょっと手作り感が出るようにしています。
⑤ 女の子を微調整
⑥ 保存
iPhoneでは共有メニューを開きます。「画像を保存」または「ファイルに保存」を選んでください。
